Send the same payment twice

Your phone loses signal mid-payment, so the app sends it again. Without protection, Alice gets paid twice. Each payment here carries a unique key, and a key can only ever move money once.

3

Fire 20 payments at once

Twenty SGD 10.00 payments from Samuel hit the ledger together. If each one simply checked the balance and then paid, several could spend the same money. Here, each payment locks both accounts first, so they take turns.
